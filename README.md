# ห้องของเรา ป.6/2 — SL6269

ระบบห้องเรียนโรงเรียนวัดศรีโลหะราษฎร์บำรุง เปลี่ยนระบบใช้งานจริงเป็น **Google Apps Script + Google Sheets แบบใช้ฟรี** ไม่ต้องใช้ Render แบบเสียเงิน ไม่ต้องเปิด Cloud Billing

## เปิดระบบจริง

เริ่มจาก [คู่มือเปิดใช้ฟรี](apps-script/README.md) และใช้ [Install.gs](apps-script/Install.gs) เพียงไฟล์เดียว คัดลอกเข้าโปรเจกต์ Google Apps Script ของครู ตั้งรหัสใน Script properties แล้ว Deploy เป็น Web app ระบบจะสร้าง Google Sheets ส่วนตัวให้เอง

การอนุญาตและเผยแพร่ครั้งแรกต้องทำด้วยบัญชี Google ของเจ้าของ ระบบนี้ยังไม่ได้รับสิทธิ์สร้างโปรเจกต์ในบัญชี Google แทนครู เว็บตัวอย่าง https://sl6269-preview.onrender.com ยังเป็น DEMO และเก็บข้อมูลแยกตามเครื่อง ไม่ใช้ URL นี้สำหรับข้อมูลนักเรียนจริง

## ความสามารถ

- หน้าโปรไฟล์ NFC และเลือกเลขที่เมื่อไม่มีพวงกุญแจ
- บัญชีครูและนักเรียน เปลี่ยนรหัสและคืนรหัสผ่านได้
- เช็กชื่อย้อนหลัง สรุปการมาเรียนรายเดือน และบันทึกเวร
- คะแนนความดีสะสม เหรียญซื้อชุด และเงินฝากเป็นคนละยอด
- ลองชุดก่อนซื้อ ซื้อครั้งเดียว ใส่หรือถอดได้ฟรี
- ครูเพิ่มสินค้า รูป HTTPS ราคา สี รูปทรง และหยุดขายได้
- ฝากถอนแบบสตางค์ คืนรายการผิดผ่านรายการชดเชยและเก็บประวัติเดิม
- ประวัตินักเรียนส่วนตัว ส่งออก CSV/JSON และลิงก์ NFC
- ข้อมูลกลางใน Google Sheets ใช้หลายเครื่อง และล็อกธุรกรรมป้องกันการบันทึกพร้อมกัน

## สำหรับผู้พัฒนา

```sh
npm run build:gas
npm test
```

แก้กติกาหลักใน server/business.mjs, server/catalog.mjs และ assets/avatar.js แล้วสร้าง Core.gs/Index.html/Install.gs ใหม่ด้วย build:gas ส่วน backend Google อยู่ใน apps-script/Code.gs อย่าแก้ generated files อย่างเดียว

server/server.mjs เป็น backend Node/SQLite รุ่นเดิมที่เก็บไว้สำหรับทดสอบและอ้างอิง ไม่จำเป็นสำหรับเส้นทางใช้ฟรี ไม่มีไฟล์ render.yaml ที่สมัครบริการเสียเงินแล้ว

Apps Script มีโควตาตามบัญชี Google เมื่อเกินโควตาต้องรอคืนสิทธิ์ ไม่ได้คิดเงินเพิ่มอัตโนมัติ ต้องทดสอบบน deployment จริงหลังอนุญาตบัญชี Google ก่อนบันทึกเงินฝากจริง

Repository นี้ไม่รวมชื่อจริง เลขประจำตัว รหัสผ่าน หรือไฟล์ส่วนตัวของนักเรียน นำเข้าข้อมูลหลังเข้าสู่ระบบครูเท่านั้น
