# ระบบจัดการห้อง ป.6/2

ระบบสำหรับครูประจำชั้นและแดชบอร์ดอ่านอย่างเดียวสำหรับผู้ปกครอง/ผู้เกี่ยวข้อง

## ความสามารถ

- เช็กชื่อแยกตามวันที่
- เช็กการทำเวร พร้อมเพิ่ม 5 คะแนนหรือหัก 5 คะแนน
- เพิ่มและหักคะแนน พร้อมเลือกหรือพิมพ์เหตุผลเอง
- บันทึกเงินออมพร้อมวันที่
- แดชบอร์ดสาธารณะแสดงเฉพาะชื่อเล่น
- หน้าครูป้องกันด้วยชื่อผู้ใช้และรหัสผ่าน

## โครงสร้างสำคัญ

- `src/worker.js` โค้ดหลักของ Cloudflare Worker
- `dist/server/index.js` ไฟล์ Worker ที่พร้อมนำขึ้นระบบ
- `drizzle/` โครงสร้างฐานข้อมูล D1
- `.openai/hosting.json` การตั้งค่าของ OpenAI Sites เดิม

## ค่าลับที่ต้องตั้งในระบบโฮสต์

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`

อย่าเขียนรหัสผ่านลงในโค้ดหรือ commit ลง GitHub
