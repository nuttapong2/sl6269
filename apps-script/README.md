# เปิดระบบห้อง ป.6/2 แบบใช้ฟรี

ใช้ Google Apps Script เป็นเว็บไซต์และระบบล็อกอิน ใช้ Google Sheets ส่วนตัวเป็นฐานข้อมูลกลาง ใช้ได้หลายเครื่อง ไม่ต้องใช้ Render และไม่ต้องเปิด Google Cloud Billing

## เริ่มใช้: คัดลอกโค้ดเพียงไฟล์เดียว

1. เปิด https://script.new ด้วยบัญชี Google ของครู สร้างโปรเจกต์ชื่อ SL6269 Classroom
2. เปิดไฟล์ [Install.gs](Install.gs) ใน GitHub กด Raw แล้วคัดลอกข้อความทั้งหมด นำไปแทนเนื้อหา Code.gs ใน Apps Script และกดบันทึก ใช้ Install.gs เพียงไฟล์เดียว ไม่ต้องนำ Code.gs, Core.gs หรือ Index.html เข้ามาซ้ำ
3. กดรูปเฟือง **Project Settings → Script properties → Add script property** เพิ่ม `ADMIN_USERNAME` เป็น `krutoey` และ `ADMIN_PASSWORD` เป็นรหัสครูที่ต้องการ (อย่างน้อย 8 ตัวอักษร) เก็บค่าในหน้านี้เท่านั้น อย่าใส่รหัสจริงใน GitHub หรือหน้าเว็บ
4. กลับ Editor เลือกฟังก์ชัน `setupClassroom_` แล้วกด Run อนุญาตให้โปรเจกต์ที่ครูสร้างเองเข้าถึง Google Sheets หากมีหน้าตรวจสอบแอป ให้ตรวจชื่อโปรเจกต์และบัญชีผู้พัฒนาให้เป็นของครูเอง ระบบจะสร้างไฟล์ Google Sheets ส่วนตัวชื่อ SL6269 Classroom — private data และลบรหัสผ่านแบบข้อความออกจาก Script properties เมื่อสร้างสำเร็จ
5. กด **Deploy → New deployment → เลือก Web app** ตั้ง **Execute as: Me** และ **Who has access: Anyone** แล้วกด Deploy และอนุญาตตามที่ Google ขอ หากบัญชีโรงเรียนไม่มีตัวเลือก Anyone ผู้ดูแลโดเมนอาจจำกัดสิทธิ์ ต้องใช้บัญชีที่อนุญาตเผยแพร่สาธารณะหรือให้ผู้ดูแลเปิดสิทธิ์นั้น
6. คัดลอก Web app URL ที่ลงท้าย `/exec` เปิดในมือถือ แล้วเข้าสู่ระบบครูด้วยบัญชีที่ตั้งไว้ ข้อมูลเริ่มต้นมีเพียงเลขที่ 1–37 ยังไม่มีชื่อจริงหรือเลขประจำตัว
7. นำเข้ารายชื่อ JSON ผ่านหน้าเว็บครู หรือเติมชื่อ/เลขประจำตัวทีละคน นักเรียนใช้เลขประจำตัวเป็นชื่อผู้ใช้และรหัสเริ่มต้น เปลี่ยนรหัสผ่านได้ในหน้าเข้าสู่ระบบ หลังบันทึกข้อมูลแล้วลองเปิดอีกเครื่องเพื่อตรวจว่าข้อมูลตรงกัน

## รูปแบบไฟล์รายชื่อ

```json
[
  {"id": 1, "name": "ชื่อนักเรียน", "schoolId": "เลขประจำตัว"}
]
```

ใช้ไฟล์รายชื่อส่วนตัวที่ครูมีอยู่ ไม่ต้องอัปโหลดขึ้น GitHub นักเรียนที่ยังไม่มีเลขประจำตัวจะยังล็อกอินไม่ได้ แก้เลขประจำตัวภายหลังได้โดยยอดเงินและคะแนนเดิมยังอยู่ การเปลี่ยนเลขประจำตัวจะคืนรหัสผ่านเริ่มต้นและออกจากระบบบัญชีนั้น

## NFC

ลิงก์รายคนมีรูปแบบ `WEB_APP_URL/exec?student=1` ใช้ปุ่มคัดลอก NFC ในหน้าโปรไฟล์หรือส่งออก CSV ลิงก์ทั้งหมดจากหน้าครู อย่าใช้ URL ของ iframe หรือเว็บตัวอย่าง Render เขียนลงแท็ก เปิดโปรไฟล์ได้โดยไม่ล็อกอิน แต่การแก้คะแนน ฝากถอน และซื้อชุดต้องผ่านสิทธิ์บัญชี

## ตรวจหลังเปิดใช้งาน

- เพิ่มความดี 100 ซื้อสินค้า 30 เหรียญ ต้องเหลือความดี 100 เหรียญ 70 และเงินฝากไม่เปลี่ยน
- ฝาก 100 บาท ถอน 25 บาท ต้องเหลือ 75 บาท เปิดอีกเครื่องแล้วได้ยอดเดียวกัน
- ลองชุดไม่หักเหรียญ สินค้าที่ซื้อแล้วสวมใส่และถอดได้ฟรี
- นักเรียนดูได้เฉพาะประวัติและเงินฝากของตัวเอง แก้คะแนนหรือเงินไม่ได้
- ล็อกอินครูเท่านั้นที่เพิ่มสินค้า เช็กชื่อย้อนหลัง และคืนรายการเงินผิดได้

## การดูแลและอัปเดต

Google Apps Script มีโควตารายวัน หากถึงขีดจำกัดจะหยุดให้บริการชั่วคราว ไม่ได้สมัครแพ็กเกจเสียเงินอัตโนมัติ ระบบนี้ไม่มี polling อัตโนมัติและไม่มีบริการที่ผูกบัตรอยู่ การรองรับการใช้งานจริงขึ้นกับบัญชี Google และจำนวนรายการในแต่ละวัน

เก็บ Google Sheets และโปรเจกต์ Apps Script เป็นส่วนตัว ไม่กดแชร์ Anyone ที่ตัว Sheets ผู้ใช้เข้าถึงผ่านเว็บแอปตามสิทธิ์เท่านั้น ข้อมูลจัดเก็บเป็น snapshot แบบแบ่งหลายเซลล์เพื่อป้องกันข้อมูลขาด ไม่ควรแก้ตารางเก็บข้อมูลโดยตรง ส่งออก JSON/CSV จากหน้าครูเพื่อสำรองข้อมูลเป็นระยะ

เมื่ออัปเดตโค้ด ให้แทน Code.gs ด้วย Install.gs รุ่นใหม่ แล้วเลือก Deploy → Manage deployments → Edit → New version → Deploy เพื่อใช้ URL เดิม ห้ามรัน setupClassroom_ ซ้ำเพื่อรีเซ็ตฐานข้อมูล ระบบจะปฏิเสธการตั้งค่าทับข้อมูลเดิม

## สถานะการตรวจ

ชุดทดสอบอัตโนมัติจำลองบริการ Google และตรวจรหัสผ่าน สิทธิ์บัญชี การซื้อชุด ฝากถอน การคืนรายการเงิน การกดซ้ำ และกรณีเขียนข้อมูลล้มเหลวแล้ว แต่ยังต้องอนุญาตบัญชี Google และทดสอบบน deployment จริงตามขั้นตอนด้านบนก่อนใช้บันทึกเงินจริง
